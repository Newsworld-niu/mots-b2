# 法语助手（frdic.com）网页版词条布局调研笔记

> 调研时间：2026-11-22，观察样本页面：`/dicts/fr/accueil`、`/dicts/fr/prendre`、`/dicts/fr/beau`（仅观察结构布局，不抓取词典内容）。

## 1. 整体页面结构

- **顶部导航 + 搜索栏（`#search-box`）**：单行搜索栏在滚动时固定在视口顶部，左侧为搜索模式选择，中间为输入框，右侧为提交按钮。
- **双栏主体**：
  - 左侧主词条栏（`#dict-body`，约 788px 宽）：包含词头区（`#exp-head`）、主标签栏与活动面板（`#tabs`）、以及底部的「历史记录 / 生词本」双标签紧凑面板。
  - 右侧边栏（约 300px 宽）：广告与推广位（Mots B2 不做广告栏，可省去或留给词库快捷跳转/历史收藏侧栏）。

## 2. 词头区（`#exp-head`）

- **标题行**：左侧大号加粗 `<h1>` 词头，行内紧跟小型矩形描边等级/考纲标签（如 `常用词`、`TEF/TCF`、`B2` 等，按词条数量动态展示）；最右侧放纠错入口与「划词」开关。
- **元信息与操作行（`.explain-word-info`）**：`<h1>` 下方单行横向排列：
  - 音标（`音标：[...]`；形容词如 `beau` 可同时展示阳/阴性音标）
  - 发音按钮（喇叭图标，Mots B2 可直接复用男声/女声双语音）
  - 收藏 / 加入生词本按钮
  - 添加笔记按钮
- 词性、变位链接、阴阳性/复数变化放在下方主面板顶部（不在词头一行堆砌）。

## 3. 标签页与折叠面板顺序（`#tabs`）

1. **主标签栏（`.ui-tabs-nav`）**：圆角/描边标签，窄屏或标签多时自动换行（1–2 行）：
   - 通用标签：`法汉释义`（默认激活）、`短语搭配`、`法语例句`、`近义·反义·派生`、`法法释义`、`词源与辨析`、`笔记`
   - 按词条条件出现：动词展示 `动词变位` 标签（紧随 `法汉释义` 之后，为第 2 个标签）
2. **默认主标签内的纵向折叠卡片（`.explain_wrap`）**：
   - 默认展开 3 个核心折叠块，每个块有统一标题栏 + 折叠箭头 + 细分割线：
     1. **法汉释义**（按词性分组 + 行内精简例句）
     2. **近义、反义、派生与词族**（紧随释义之后，分 `<h5>` 小节）
     3. **法语例句库**（编号双行卡片，带发音按钮与目标词高亮）
   - 点击次级标签（如 `动词变位`、`短语搭配`、`法法释义`、`词源`、`易混词`、`笔记`）可快速聚焦到对应完整面板，既保证默认页信息完整直观，又能一键切到专项内容，避免长词条（如 `prendre`）无限向下滚动找不到重点。
3. **词条页底部**：紧凑的「最近查词 / 收藏夹」切换面板。

## 4. 词条内部语言要素的排版与密度

- **词形变化（Forms）**：形容词/名词在「法汉释义」第一组词性上方用紧凑一行列出阴性、复数及特殊词形（如 `f. belle / pl. beaux / f.pl. belles`）；动词在顶部提供显眼的「查看动词变位」跳转提示链接，点击切到 `动词变位` 标签。
- **词性分组（`.cara`）**：使用醒目的主题色加粗小标题分隔各词性（`n.m.`、`v.`、`adj.`、`adv.`、`loc.`）。
- **编号义项（`.exp`）**：`1. 2. 3.` 编号展示，中文义项用分号 `；` 分隔；语域/学科/法语小标签（如 `[书]`、`[俗]`、`[转]` 或法语简短义项提示）以胶囊/括号贴合行内展示；每个义项下方紧跟 1–2 条轻量例句。
- **例句区（`.lj_item`）**：编号卡片，第一行为法语原句（目标词高亮着重，右侧配朗读按钮），第二行为中文译文；支持整句朗读。
- **搭配与短语**：既有主释义内 `loc.` 常见用法，也有独立 `短语搭配` 标签汇总。
- **近反义 / 派生 / 词族**：`<h5>` 小标题分组 + 可点击词条胶囊（带简短中文提示时并列展示），点击直接跳转到对应词条。
- **视觉适配**：保留法语助手「上释义、下例句、多面板折叠、顶部标签切换」的高效信息架构与密度，视觉颜色、字体（Fraunces + 正文字体）、圆角与深色模式完全沿用 Mots B2 现有设计 token。
